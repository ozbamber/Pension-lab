# Pension Lab — התחלה מהירה

הקובץ `pension-lab-he-standalone.html` הוא הגרסה העצמאית. אפשר לפתוח אותו ישירות בדפדפן ללא התקנה וללא שרת.

תיקיית `pension-lab-he/` מכילה את קוד המקור, מנוע החישוב, העיצוב, הבדיקות, סקריפט בניית הקובץ העצמאי, בדיקת Chromium, צילומי QA, מקורות ויומן שינויים.

פקודות עיקריות מתוך תיקיית המקור:

```bash
node tests.js
node build-standalone.js
node browser-smoke.js
```

סטטוס מסירה: 23/23 בדיקות מנוע עברו; בדיקת Chromium בדסקטופ ובמובייל עברה ללא שגיאות ריצה וללא גלישה אופקית.
