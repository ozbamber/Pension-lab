# Codex Handoff — Pension Lab

## מטרת הפרויקט

Pension Lab הוא מחשבון/סימולטור פנסיוני בעברית מלאה וב-RTL, שנועד לאפשר למשתמש לבחון צבירה וקצבה תחת הנחות שונות בלי להציג את התוצאה כייעוץ אישי.

## מה כבר עובד

האפליקציה כוללת:

- גיל נוכחי וגיל פרישה.
- יתרה קיימת ושכר.
- שכר מבוטח.
- הפקדות לפי אחוזים או סכום.
- שלבי שכר לאורך השנים.
- שלבי תשואה ריאליים או נומינליים.
- אינפלציה.
- הפסקות עבודה.
- דמי ניהול.
- מקדם קצבה.
- מעבר בין שקלים של היום לשקלים עתידיים.
- גרפי צבירה.
- Explorer לגיל פרישה.
- תרחישים שמרני / בסיס / צמיחה.
- שמירת תרחישים ב-localStorage והשוואה ביניהם.

## שיפורים שכבר בוצעו בסבב האחרון

- תוקנה בחירת שלבי שכר ותשואה לאחר הגבול האחרון ובמקרים של gap בין שלבים.
- תוקן פירוק הצבירה כך שהפקדות ודמי ניהול מוצגים באופן עקבי יותר.
- נוספה הבחנה פנימית בין הפקדות ברוטו/נטו ודמי ניהול מהפקדה/צבירה.
- חוזק normalization של שלבים, הפסקות עבודה, גילאים, שיעורים ומקדמים.
- נוסף fallback כאשר localStorage אינו זמין.
- save/reset נשארים נגישים גם במובייל.
- בוצעו שיפורי נגישות, focus, resize וגרפים.
- נוסף build דטרמיניסטי ל-standalone HTML.

## QA שכבר בוצע

- 23 בדיקות מנוע עברו בהצלחה בסבב האחרון.
- Chromium smoke QA עבר בדסקטופ ובמובייל.
- לא נמצאו שגיאות Console/JavaScript בסבב האחרון.
- נבדקו בין היתר: שינוי גיל פרישה, הוספת הפסקת עבודה, real/nominal, פתיחת רכיב ההבטחה, שמירת תרחיש ואיפוס.
- אין לטעון שבוצע QA מלא ב-Safari/Firefox או עם screen reader.

## ההחלטה העסקית הנוכחית

המשתמש רוצה לפרסם את המוצר כך שיהיה נגיש מכל מחשב, **ללא עלות בשלב זה**, אבל עם בסיס שיאפשר בהמשך:

- לראות כמה משתמשים/מבקרים יש.
- למדוד שימוש בתכונות.
- לחבר domain בעתיד.
- לבחון פרסומות/monetization בעתיד.

מסלול ההפצה שנבחר ככיוון:

**GitHub -> Cloudflare Pages -> `pages.dev` -> Web Analytics**

בשלב הראשון אין צורך ב-domain בתשלום, backend, login או DB.

## מגבלה חשובה

התרחישים נשמרים כיום ב-localStorage ולכן הם מקומיים לדפדפן/מחשב. פרסום האפליקציה באינטרנט אינו מסנכרן אותם בין מכשירים.

אם בעתיד רוצים login, סנכרון, שמירה בענן או שיתוף תרחיש בקישור — זו הרחבת מוצר נפרדת שדורשת backend/storage ותכנון פרטיות.

## מה לעשות כשממשיכים

1. קרא את `AGENTS.md`.
2. פתח את `pension-lab-he/README.md`, `QA.md`, `CHANGELOG.md` ו-`SOURCES.md`.
3. הרץ את הבדיקות הקיימות לפני שינוי.
4. אל תשבור את הגרסה הסטטית.
5. אם המשימה הבאה היא deployment, הכין repo מבנה נקי המתאים ל-GitHub + Cloudflare Pages, בלי להוסיף עלויות או backend.
6. אם מוסיפים analytics, שמור אותו privacy-conscious ולאסוף אירועי מוצר רק כאשר המשתמש מבקש מעבר לסטטיסטיקה בסיסית.
