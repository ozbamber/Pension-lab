# Deployment Next — ללא עלות

## יעד

להעלות את Pension Lab לאינטרנט כך שיהיה נגיש מכל מחשב, בלי עלות חודשית בשלב הראשון, ועדיין להשאיר נתיב טוב ל-analytics ולצמיחה עתידית.

## מסלול מומלץ

1. ליצור GitHub repository לפרויקט.
2. להעלות את `pension-lab-he/` ואת קבצי התיעוד הרלוונטיים.
3. לחבר את repository ל-Cloudflare Pages.
4. לפרסם באמצעות כתובת חינמית מסוג `pension-lab.pages.dev` או שם זמין אחר.
5. להפעיל Cloudflare Web Analytics אם רוצים נתוני תנועה בסיסיים.
6. domain פרטי ניתן להוסיף מאוחר יותר — אין צורך לרכוש עכשיו.

## Build

הפרויקט הוא static HTML/CSS/JS. אין צורך בשרת application לצורך deployment הראשוני.

אם Cloudflare משרת את קוד המקור ישירות, ודא שה-entry point הוא `index.html` מתוך תיקיית הפרויקט המתאימה. אפשר גם ליצור build output מסודר אם רוצים להפריד source מ-public.

## מה לא לעשות כרגע

- לא להוסיף DB.
- לא להוסיף login.
- לא לקנות domain רק לצורך MVP.
- לא להוסיף שירות analytics בתשלום.
- לא להוסיף פרסומות לפני שיש נתוני שימוש ודרישה מפורשת.

## Analytics עתידי

בשלב ראשון מספיקים visitors/page views/referrers בסיסיים. בהמשך, אם רוצים להבין שימוש במוצר, כדאי למדוד אירועים כגון:

- שינוי גיל פרישה.
- שימוש ב-Explorer.
- שמירת תרחיש.
- השוואת תרחישים.
- הוספת הפסקת עבודה.
- מעבר real/nominal.

יש לתכנן event tracking כך שלא ישלח פרטים פיננסיים שהוזנו על ידי המשתמש ללא צורך והסכמה מתאימה.
